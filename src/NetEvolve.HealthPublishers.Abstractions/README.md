# NetEvolve.HealthPublishers.Abstractions

[![NuGet Version](https://img.shields.io/nuget/v/NetEvolve.HealthPublishers.Abstractions.svg)](https://www.nuget.org/packages/NetEvolve.HealthPublishers.Abstractions/)
[![NuGet Downloads](https://img.shields.io/nuget/dt/NetEvolve.HealthPublishers.Abstractions.svg)](https://www.nuget.org/packages/NetEvolve.HealthPublishers.Abstractions/)
[![License](https://img.shields.io/github/license/dailydevops/healthpublishers.svg)](https://github.com/dailydevops/healthpublishers/blob/main/LICENSE)

Shared abstractions and base classes used by all `NetEvolve.HealthPublishers.*` packages to implement `Microsoft.Extensions.Diagnostics.HealthChecks.IHealthCheckPublisher`.

> [!IMPORTANT]
> This package is under construction. Implementation is tracked in [issue #2](https://github.com/dailydevops/healthpublishers/issues/2).

## Installation

### NuGet Package Manager

```powershell
Install-Package NetEvolve.HealthPublishers.Abstractions
```

### .NET CLI

```bash
dotnet add package NetEvolve.HealthPublishers.Abstractions
```

### PackageReference

```xml
<PackageReference Include="NetEvolve.HealthPublishers.Abstractions" Version="x.x.x" />
```

## Requirements

- .NET 8.0 or higher
